        Privacy
        
OmSuite is local-first: no account, no login, no cloud storage, no sync,
        no subscription, and no telemetry. Your files never leave this PC through
        OmSuite. The app makes no network requests while running. Recents and
        favourites are stored as file paths only, in the app data folder shown
        below — never file contents.
